# KANC 연구과제 관리 연습용

가상 데이터 기반 한국어 연구과제 관리 웹앱을 위한 실습 저장소입니다.

**첫 실행 버전 v1.0** — 설치나 API 키 없이 연구과제를 검색하고, 상태를 바꾸고, 주요 현황을 확인합니다. 실제 한국나노기술원 사업·인력·예산과 무관한 가상 과제 12건을 제공합니다.

## 바로 실행하기 (가장 쉬운 방법)

1. GitHub 저장소의 **Code → Download ZIP**을 누릅니다.
2. 내려받은 ZIP을 **모두 압축 해제**합니다.
3. 압축을 푼 폴더의 **index.html**을 Chrome 또는 Edge 등 최신 브라우저로 엽니다.

Node.js, Python, npm 설치 없이 실행됩니다. `index.html`, `styles.css`, `data.js`, `core.js`, `app.js`를 같은 폴더에 유지하세요. 네트워크 연결 없이도 동작하며 외부 폰트·라이브러리·API를 호출하지 않습니다.

브라우저가 파일 실행이나 저장을 제한한다면, Python이 설치된 환경에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 여세요.

```bash
python -m http.server 8000 --bind 127.0.0.1
```

위 명령은 `index.html`이 있는 폴더에서 실행합니다. 종료할 때는 `Ctrl+C`를 누릅니다. 로컬 파일 실행과 localhost 실행은 저장 공간이 서로 다릅니다.

## 사용할 수 있는 기능

| 기능 | 동작 |
| --- | --- |
| 주요 현황 | 전체 과제·진행·종료 건수, 전체기간 총 연구비, 일정 점검 건수 |
| 목록·검색 | 과제명·번호·책임자·부서로 검색 |
| 필터·정렬 | 상태·부서·수행연도 필터, 종료일·과제명·연구비 정렬 |
| 상태 관리 | 목록의 선택창에서 기획·진행·보류·종료로 즉시 변경 |
| 상세·수정 | 과제명을 클릭해 기간·책임자·연구비·진행률·메모 수정 |
| 가상 과제 등록 | 필수 항목과 기간·금액·중복 번호를 검사하고 새 과제 등록 |
| CSV 내려받기 | 현재 검색·필터 결과를 한글 Excel 호환 CSV로 저장 |
| 초기화 | 확인창에서 동의하면 수정 내용을 지우고 가상 12건으로 복원 |

- 모든 현황 카드는 **현재 검색·필터 결과**를 집계합니다.
- 수행연도는 시작연도부터 종료연도까지를 포함합니다. 여러 해에 걸친 과제도 해당 연도 검색에 포함됩니다.
- 연구비 단위는 **백만원**이며 전체 수행기간 총액입니다. 100백만원 = 1억원입니다. 연도 필터를 적용해도 해당 과제의 전체기간 연구비를 표시하며 연차별 예산으로 나누지 않습니다. 기획·보류·종료 과제도 검색 결과에 있으면 총액에 포함됩니다.
- 진행률은 직접 입력하는 업무 진척도입니다. 상태를 **종료**로 바꾸면 100%로 저장합니다. 다시 진행·기획·보류로 바꿀 경우 진척도는 유지되므로 상세창에서 필요에 맞게 수정하세요.
- 일정 점검은 **진행·보류** 과제 중 종료일까지 30일 이내인 과제와 종료일이 지난 과제를 셉니다. 한국시간 기준이며 실제 지연 확정 판정은 아닙니다.
- 입력 오류나 중복이 있는 저장 행은 목록과 집계에서 제외하고 안내합니다. 읽을 수 없는 저장 데이터는 가상 데이터로 표시하며, 사용자가 저장·초기화하기 전에는 기존 저장값을 덮어쓰지 않습니다.

## 데이터 저장 범위

변경 내용은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 같은 실행 주소·같은 브라우저에서 새로고침하면 유지됩니다. 저장이 차단되거나 용량이 부족하면 화면에 실패 안내를 표시합니다.

다른 PC·브라우저·사용자에게 자동 공유되지 않습니다. 시크릿 모드 종료, 브라우저 데이터 삭제, 파일 경로 변경 등에 따라 저장값이 사라지거나 다른 저장 공간을 사용할 수 있습니다. 필요한 결과는 CSV로 보관하세요. CSV는 조회·보관용이며 재업로드 기능은 없습니다.

이 버전은 연습용입니다. 로그인·권한 관리·공유 DB·기관 시스템 연동·예산회계 기능은 포함하지 않습니다. **실제 기관 자료나 개인정보를 입력하지 마세요.**

## 테스트 데이터

- `data/sample-projects.json`: 읽기 쉬운 원본 가상 데이터
- `data.js`: 로컬 파일 실행을 위한 동일 데이터의 JavaScript 버전
- 초기 상태: 총 **12건**, 진행 **7건**, 종료 **2건**, 기획 **2건**, 보류 **1건**
- 전체기간 연구비 합계: **13,800백만원 = 138억원**
- 2026-10-17 기준 일정 점검: **3건**. 이 값은 실행 날짜에 따라 달라집니다.

테스트 데이터를 변경할 때는 두 파일을 함께 수정하세요. 자동 테스트가 일치 여부를 확인합니다. 이미 저장된 브라우저에서는 **가상 데이터로 초기화**해야 변경된 예시가 보입니다.

## 개발·검증

개발 검증에만 Node.js 18 이상이 필요합니다. 외부 패키지가 없으므로 `npm install`은 필요 없습니다.

```bash
npm test
npm run check
```

`npm test`는 Node 기본 테스트 러너로 검색·필터·집계·기간 계산·입력 검증·저장 복원·오류 처리·CSV 안전 처리와 DOM 어댑터 기반 등록·수정·상태 변경 흐름을 검사합니다. `npm run check`는 JavaScript 구문을 검사합니다.

자동 검증 결과: **19개 테스트 통과**, JavaScript 구문 검사 통과. 현재 제작 환경에서는 실제 브라우저 시각 검증을 실행하지 않았습니다. DOM 어댑터 검증은 실제 브라우저 테스트를 대신하지 않습니다.

브라우저에서 처음 열었을 때 아래를 확인하세요.

1. 과제 12건, 총 연구비 138억원이 표시되는지 확인합니다.
2. `GaN` 검색 시 1건이 표시되고, 필터 초기화 시 12건으로 돌아오는지 확인합니다.
3. 목록에서 상태를 종료로 변경하고 새로고침해 상태·진행률 100%가 유지되는지 확인합니다.
4. 과제명을 클릭해 메모를 바꾸고 저장합니다. 잘못된 기간은 저장이 거부되어야 합니다.
5. CSV를 내려받아 한글과 현재 검색 결과를 확인합니다.
6. 가상 데이터로 초기화해 원래 12건으로 돌아오는지 확인합니다.
