# KANC 연구과제 관리 연습용 웹앱

한국어 화면에서 **과제 목록, 총 연구비, 전체 과제 수, 진행·종료 상태, 연도별 조회**를 연습하는 작은 웹앱입니다. 모든 과제·이름·금액은 가상 데이터입니다. 실제 KANC 서비스나 데이터베이스에 연결하지 않습니다.

## 가장 쉬운 실행 방법 (설치 불필요)

1. GitHub 저장소 위쪽의 초록색 **Code** 버튼 → **Download ZIP**을 누릅니다.
2. 다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 폴더 안의 **index.html**을 더블클릭합니다.
4. Edge 또는 Chrome에서 연구과제 화면이 열리면 완료입니다. 나머지 파일도 같은 폴더에 그대로 두세요.

로그인, 프로그램 설치, 인터넷 연결이 필요하지 않습니다. GitHub 파일 미리보기에서는 앱이 실행되지 않으므로 ZIP을 내려받아 열어 주세요.

## 화면에서 확인해 보세요

오른쪽 위 **조회 연도**를 바꾸면 목록과 네 개의 요약 카드가 함께 바뀝니다.

| 조회 연도 | 전체 과제 | 총 연구비 | 진행 | 종료 |
|---|---:|---:|---:|---:|
| 전체 연도 | 8건 | 1,300,000,000원 | 3건 | 5건 |
| 2026년 | 3건 | 650,000,000원 | 2건 | 1건 |
| 2025년 | 3건 | 440,000,000원 | 1건 | 2건 |
| 2024년 | 2건 | 210,000,000원 | 0건 | 2건 |

- 연도는 각 과제의 **기준 연도**입니다. 여러 해에 걸친 과제도 기준 연도에서만 집계합니다.
- 연구비는 각 과제에 입력된 **총액**을 합산합니다. 연도별 집행액이 아닙니다.
- 진행·종료는 가상 데이터의 지정값이며 오늘 날짜에 따라 자동 변경되지 않습니다.
- 좁은 화면에서는 과제 표를 좌우로 스크롤할 수 있습니다.
- 이 버전은 조회 연습용입니다. 과제 등록·수정·삭제와 저장 기능은 없습니다.

## 개발용 실행과 자동 테스트 (선택)

Node.js 18 이상이 있는 컴퓨터에서 이 폴더를 터미널로 열어 실행합니다. 외부 패키지 설치는 필요 없습니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 열면 됩니다. 서버 종료는 터미널에서 **Ctrl+C**를 누릅니다. 포트 사용 중 오류가 뜨면 실행 중인 이 연습용 서버를 종료하거나 위의 더블클릭 방법을 사용하세요.

```sh
npm test
```

전체·연도별 합계, 빈 결과, 원화 표시, 데이터 유효성, HTTP 파일 응답을 검사합니다.

## 파일 안내

- `index.html`: 화면 구조
- `styles.css`: 색상·배치·모바일 대응
- `projects.js`: 가상 데이터와 필터·집계 계산
- `app.js`: 연도 선택과 화면 갱신
- `server.cjs`: 선택적으로 실행하는 로컬 서버
- `test/projects.test.cjs`: 자동 테스트

운영 서비스 배포 설정, API 키, 실제 연구 정보는 포함하지 않습니다.
